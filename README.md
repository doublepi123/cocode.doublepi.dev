# CoCode product website

Public bilingual product page for [CoCode](https://github.com/doublepi123/co_code), the Android app that runs Cox locally without root.

**Website: https://cocode.doublepi.dev/**

This repository contains only the static website, CoCode's official icon, and the project's license and notice. It does not include an app binary, credentials, user projects, or a hosted coding-agent service.

GitHub Pages publishes the root of the `main` branch through the `CNAME` file. Download links use CoCode's Releases page so the website does not pin an outdated APK.

The site links to [Cox](https://doublepi123.github.io/), and the Cox homepage links back here. CoCode and Cox run independently; the website does not imply a remote connection between them.
